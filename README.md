# चाय की दुकान — Android APK

This repository wraps the responsive Chaiki Tapri web app inside a lightweight Android WebView.

## Build on GitHub
1. Create a GitHub repository.
2. Upload all files from this project to the repository.
3. Push to `main` (or run **Actions → Build APK → Run workflow**).
4. Open the completed workflow run.
5. Under **Artifacts**, download `chaiki-tapri-apk`.
6. Extract it and install `app-debug.apk` on Android.

The HTML, responsive desktop/mobile backgrounds, playlist and local music folder are bundled inside the APK.
